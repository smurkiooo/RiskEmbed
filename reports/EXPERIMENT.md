# AmEx: результаты эксперимента

Полный источник AmEx. Локальный test состоит из отдельных клиентов официального train; leaderboard и OOT здесь не оцениваются.

Checkpoint / число деревьев выбираются только на valid. Один seed: 42; интервалы отражают перевыборку клиентов, не обучение между seed.
Сдвинутый срез содержит сокращённую историю с прежними метками. Для временной валидации он не подходит.

Источник: 5,531,451 выписок, 458,913 клиентов.
SHA256 parquet: `f300ac65c0e650e4a4a6969995874ed28366be2a0a2beeb9931eaec26db3de6d`.

Из-за прореженного отрицательного класса score без коррекции/калибровки не является банковской PD.

## Что означают результаты

LightGBM на агрегатах: Gini 0.92295. Наибольший Gini среди сравниваемых моделей: 02_agg+coles_vicreg: 0.92363. Это сравнение при фиксированном бюджете и одном seed; выбор модели по test остаётся исследовательским наблюдением.

Пользу модификации оценивайте по парному CI разницы вместе с самим приростом Gini. Исторический test уже просматривался; новые исследования требуют заранее зафиксированного протокола.
