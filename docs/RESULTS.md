# Результаты полного запуска AmEx

Полный запуск после рефакторинга выполнен на 458 913 клиентах и 5 531 451 выписке.
Train: 275 712 клиентов; valid: 91 155; локальный test: 92 046.
Результаты получены в полном режиме с одним seed (42).

| Модель | Gini test | Δ к агрегатам | Парный 95% CI разницы |
|---|---:|---:|---|
| LightGBM: агрегаты | 0.922951 | — | — |
| LightGBM + CoLES/VICReg | 0.923629 | +0.000678 | [+0.000174; +0.001146] |
| LightGBM + остаток | 0.923218 | +0.000267 | [-0.000216; +0.000759] |
| Transformer с нуля | 0.917034 | -0.005917 | [-0.006851; -0.005151] |
| Transformer после CoLES | 0.917491 | -0.005459 | [-0.006329; -0.004684] |

## Что означают результаты

У гибрида с обычным эмбеддингом небольшой положительный прирост на этой выборке.
Интервал по перевыборкам клиентов не включает ноль, но основной эксперимент использует
один seed, а исследовательский test уже просматривался. Чтобы судить о практической пользе для банковского скоринга, нужны повторные
обучения и проверка на другой выборке. Поправка на множественные сравнения не выполнялась.

Прямые supervised Transformer уступают LightGBM на агрегатах. Предобучение
даёт около +0.00046 Gini к scratch; парный интервал [-0.00010; +0.00103] включает ноль.
Линейная ridge-проекция по агрегатам объясняет медианно около 69.6% дисперсии компонент
эмбеддинга на train. Гибрид с остатком уступает гибриду с обычным эмбеддингом.

## Высокие метрики и аудит

Gini 0.91703 у scratch соответствует ROC-AUC 0.95852; sklearn независимо воспроизвёл
результат по исходному train_labels.csv. Один P_2__last даёт test AUC около 0.91579.
Явные пересечения клиентов, повторяющиеся агрегатные профили, подстановка target
в признаки и несоответствие меток сохранённых test scores в проверенных сценариях не найдены.
Shuffle-control на реальных историях и трёх seed даёт средний AUC около 0.501.

Эти проверки не исключают скрытые прокси будущего в анонимизированном источнике.
Нет оригинального CSV для проверки преобразований и нет размеченного локального OOT.
